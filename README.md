## Цель работы
Освоить полный цикл консолидации данных из нескольких источников: загрузку, проверку качества, очистку, построение реляционной модели, расчёт выручки и формирование обоснованных управленческих решений.

## Постановка задачи (Вариант 5)
Необходимо объединить справочник субъектов (CSV), события с объёмом (Excel) и цены, заданные для событий (JSON).
* **Предметная область:** Банковский ритейл
* **CSV:** Отделения (справочник субъектов)
* **XLSX:** Операции (события, объём в единицах: транзакций)
* **JSON:** Комиссии (цены, разрез: тип комиссии)
* **Аналитическая задача:** Эффективность отделений: выручка на одну операцию.
